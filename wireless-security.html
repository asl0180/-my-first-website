Week 6: Wireless Network Security

This section explains wireless networking, Wi-Fi performance, troubleshooting commands and wireless security. It also introduces Wi-Fi 7, Artificial Intelligence (AI) and Multi-Link Operation (MLO).

1. Wireless Network Fundamentals

Wireless networks allow computers and other devices to exchange information without using physical network cables. They commonly use radio frequency (RF) electromagnetic waves.

  • RF: Radio frequency signals are commonly used by Wi-Fi.
  • IR: Infrared is used for short-range communication, such as remote controls.
  • Access Point (AP): Connects wireless devices to a network.
  • WNIC: A wireless network interface card allows a device to connect wirelessly.
  • Antenna: Transmits and receives wireless signals.

2. Wireless Signal and Interference

Wireless performance depends on signal strength, distance, obstacles, interference and the number of devices using a channel.

  • Absorption: Materials such as concrete and wood can reduce signal strength.
  • Reflection: Signals bounce off objects.
  • Scattering: Signals spread after encountering objects.
  • Multipath fading: Reflected signals can interfere with the direct signal.
  • Channel congestion: Many devices using the same channel can affect performance.

Common 2.4 GHz Wi-Fi channels

Channels 1, 6 and 11 are commonly used as non-overlapping 20 MHz channels in 2.4 GHz Wi-Fi.

3. Wireless Network Configurations

  • BSS: A group of wireless devices served by one access point.
  • ESS: Multiple access points provide connected wireless coverage.
  • IBSS: An ad-hoc wireless network where devices communicate without an access point.

4. Wi-Fi Standards

Wi-Fi generation IEEE standard Main feature
Wi-Fi 5 802.11ac Wireless improvements using 5 GHz
Wi-Fi 6 802.11ax Improved efficiency in busy networks
Wi-Fi 6E 802.11ax Adds support for the 6 GHz band
Wi-Fi 7 802.11be Includes Multi-Link Operation (MLO)

5. Windows Network Troubleshooting Commands

These commands help investigate wireless connections and network problems.

Command Purpose
netsh wlan show interfaces Displays current wireless connection information.
netsh wlan show networks mode=bssid Displays nearby wireless networks and access-point details.
netsh wlan show drivers Displays wireless adapter capabilities.
ipconfig /all Displays IP configuration details.
ping 1.1.1.1 -n 10 Tests connectivity and response times.
nslookup example.com Checks DNS name resolution.
tracert 1.1.1.1 Shows the route towards an external IP address.
netstat -ano Displays active connections and process IDs.

6. Wireless Network Security

  • WEP: An obsolete and insecure wireless security method.
  • WPA2: Widely used wireless protection, particularly with AES.
  • WPA3: A newer wireless security standard.
  • Open Wi-Fi: Does not provide ordinary Wi-Fi link encryption.

What is an evil twin hotspot?

An evil twin is a fake wireless access point that imitates a legitimate network. An attacker may use a familiar network name to encourage people to connect. Users should verify the correct network before connecting.

7. Wi-Fi 7 and Multi-Link Operation

Wi-Fi 7 uses the IEEE 802.11be standard. Multi-Link Operation (MLO) allows compatible devices to use multiple wireless links. This can help improve performance and reliability, depending on equipment and network conditions.

8. AI in Network Troubleshooting

Artificial Intelligence can help suggest possible causes of slow Wi-Fi connections by analysing measurements such as latency, signal strength and download speed.

However, network engineers must check AI recommendations against real measurements and reliable evidence.
